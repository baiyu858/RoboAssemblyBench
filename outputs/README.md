# RoboAssemblyBench 周度计划

## 总体目标

1. 将现有子技能封装成统一 API，供任务规划调用。
2. 增加基础域随机化，完成其余 6 个 Fabrica 装配任务。
3. 逐步生成约 20,000 条数据。
4. 接入 RoboBrain，实现新任务拆解和技能规划。

## 当前进展

- 双 UR5e 与 Robotiq 2F-85 环境和资产已经可以复现。
- `fabrica_plumbers_block_ur5e_right_base_prepare` 已完成物理一致的抓取与装配。
- 已具备 YAML 任务配置、本地技能注册、IK 连续控制、双臂避让和接触判断。
- 代码、环境说明、资产和演示视频已经发布。

## 第一周：模板任务完善

- 修复主要组件的抓取和放置位姿。
- 处理隔空抓取、穿模、错误吸附和关节快速翻转问题。
- 完善夹爪资产、碰撞处理和基础复现流程。

## 第二周：技能接口整理

- 梳理现有抓取、抬升、搬运、对准、插入、释放和退回技能。
- 设计统一的技能输入、输出、状态和错误接口。
- 建立技能注册与参数校验机制。
- 先使用当前任务验证技能 API 的基本调用流程。
- 整理其余 Fabrica 任务所需的资产、装配顺序和技能清单。

阶段目标：完成技能 API 初版，并保证当前任务能够通过新接口运行。

## 第三周：随机化与任务迁移

- 增加物体位置、背景、灯光、桌面纹理和物体纹理随机化。
- 保存随机种子和配置，保证生成结果可以复现。
- 以当前任务为模板，逐步添加其余 6 个 Fabrica 任务。
- 优先调通每个任务的基本抓取和装配流程，再处理细节稳定性。
- 开始接入 RoboBrain，验证结构化任务拆解和技能选择。

阶段目标：随机化框架可以使用，其余任务具备基本运行能力。

## 第四周：数据生成与规划联调

- 修复新任务运行中发现的抓取、碰撞和放置问题。
- 根据机器资源逐步扩大并发，生成约 20,000 条数据。
- 对生成结果进行基本成功检查和少量视频抽检。
- 将 RoboBrain 输出转换为技能序列，并接入仿真执行。
- 记录失败原因，为后续重规划和技能补充提供依据。
- 更新运行文档、任务配置和数据说明。

阶段目标：完成一版多任务数据集，并跑通 RoboBrain 在线规划的基本闭环。

## 基本要求

- 抓取和装配过程不应出现明显隔空抓取、穿模或释放吸附。
- 任务、随机种子、随机化参数和执行结果需要保存在数据中。
- 数据生成采用分批写盘和受控并发，避免内存占用过高。
- LLM 输出在执行前需要经过技能白名单和参数检查。
- 数据量根据实际生成速度适当调整，优先保证数据有效和流程可复现。
