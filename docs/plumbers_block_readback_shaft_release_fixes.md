## 2. 图像与状态读取优化

此前每个物理步都可能重复读取图像、关节状态、末端位姿与 FK。现在将两种缓存分别绑定到实际渲染帧和物理帧：

- `internutopia/core/runner.py` 记录渲染帧序号，向传感器传递当前是否完成渲染。
- `internutopia/core/sensor/render_frame_cache.py` 和 `internutopia_extension/sensors/rep_camera.py` 只在新渲染帧读取图像，其余步复用已有帧；返回只读数组视图，避免下游修改缓存图像。
- `internutopia/core/util/physics_frame_cache.py` 按模拟器实例、物理步、仿真时间及步长复用同一步的测量结果。
- `ur5e.py`、`ik_controller.py`、`gripper_controller.py`、任务类及 RL 后端接入共享读取；机器人复位、关节直接写入和快照恢复会使对应缓存失效。
- `rollout_performance.py` 增加状态、图像读取缓存统计。接触、滑移和安全检查仍逐物理步执行。

可设置 `INTERNUTOPIA_LEGACY_OBSERVATIONS=1` 进行旧读取方式对照。已有 4,800 步原生对照耗时从 189.68 s 降至 184.29 s，约减少 2.85%，阶段及最终物理状态一致。读取次数的大幅下降不能等同于整套任务按同等比例加速；当前完整运行仍需约 60 分钟，尚未达到 30 分钟目标。

## 3. 减少两销运输翻转和绕行

`roboassemblybench/core/axial_transport.py` 仅为显式允许任意释放自转的圆销选择较短的等效轴向朝向。围绕固定 CAD 轴心调整目标位姿，保留孔轴、轴心和插入深度，不移动仿真刚体，也不改写抓取参考点。

`fabrica_canonical.py` 将该等效朝向同步到运输、插入路径及最终目标；对于高于原运输面的孔前悬停点，允许从取料净空点直接斜升过去，保留取料净空和后续精细收敛。该路径只对两销启用。

当前 recipe 中：

- `physical_free_axial_transport_parts` 和 `physical_direct_transport_to_hover_parts` 为 `['1', '4']`。
- 两销相对固定抓取参考点的持有转角上限为 10°，任务层及 RL 执行层共用；其他零件沿用各自设置。
- 两销平移滑移保护仍为 3 mm。10° 持有转角与释放后轴倾斜、自转判定是不同检查。

## 4. 整根销轴对齐与受力卸载

只把销尖移到入口，不能保证后面的销轴同时通过紫件与绿件。倾斜或偏心会产生侧向顶压，并通过力臂形成较大手腕接触力矩。

`roboassemblybench/core/rl/axis_alignment.py` 按接收零件的实测位姿检查四个孔截面。新增 `bore_fit.py` 平衡最差截面误差，而不只减小误差平方和；不满足对齐条件时限制继续送入，连续不兼容时明确失败。

两销都启用 `keep_grip_direction`，保持已选夹持方向，校正横向位置及轴线倾斜。名义径向间隙为 0.25 mm，安全余量 0.02 mm，对齐允许误差为 0.23 mm。执行器限制指令领先，并根据实际发布的关节命令回算虚拟目标，避免积累被拒绝的顶压指令。

新增 `torque_relief.py`：手腕力矩达到 1.2 N·m 软限时，在两手真实夹持仍有效的条件下允许限速、限行程卸载；降至 0.9 N·m 后退出卸载，避免在阈值附近反复切换。卸载期间不继续正向送入，原有接触、滑移、行程及 4 N·m 硬限仍生效。`runtime.py`、训练环境、recipe、资格验证及权重元数据同步传递执行配置；当前权重文件未重新训练或改写。

本轮第一销 RL 插入期间手腕力矩峰值约 0.283 N·m。最终释放后，第一销固定特征点误差约 0.369 mm、轴倾斜约 0.156°；第二销约 0.249 mm、0.128°。轴向自转不纳入这两个倾斜角度。

## 5. 第二销分段释放

上一轮完整运行已完成两销插入，但第二销松爪时，左夹爪张开扫到右夹爪内侧，导致右臂紫件支撑的一侧接触力降至近零。局部接触诊断记录到跨夹爪接触峰值约 247 N。

新增 `roboassemblybench/core/plumbers_release.py` 编译释放流程，`toolkits/factory_dual_franka_assembly/physical_release.py` 判断真实脱离，任务类负责阶段内的接触确认，技能执行器限制张爪速率。当前仅第二销配置该流程：

1. 左爪限速张到归一化开度 0.34，实测至少 0.33。
2. 两侧销接触探针必须有效，且两侧接触力均低于 0.1 N，连续确认 6 个物理步。传感器无效或同一步重复读取不累计确认数。
3. 保持有限开度及夹持方向，沿进入撤离阶段时捕获的紫件局部 +Z 方向撤出 60 mm，速度 0.03 m/s。撤离目标固定，不逐步跟随零件漂移。
4. 撤离完成后完全张爪，再停靠。右臂全程继续提供真实夹持支撑。

局部续跑通过，跨夹爪接触峰值由约 247 N 降至 0，紫件位移由约 1.079 mm 降至 0.025 mm。随后本轮从初始场景连续运行也通过该释放流程、右臂释放、双臂 home 和最终无夹持检查。本轮未启用诊断碰撞过滤，也未通过临时固定关节、运动学搬运或锁定零件实现释放。
